# Cyclone Intensity Inference

> 热带气旋卫星影像强度分类模型的**推理验证与应用扩展**工程。独立Git仓库（规划 V0.3，2026-10-10）；当前尚未创建 GitHub 远程或实现可运行源码。

## 项目目标

以可信来源的既有模型权重作为起点，构建可复现的本地推理、输入预处理、类别概率解析、连续 Dvorak T-number 估计、独立效果检验和应用服务。当前重点是**固定模型的推理与应用**，不承担训练、微调或训练方案复现。

初始参考模型来自 [EnceladusCat/Cyclone-Intensity-ML](https://github.com/EnceladusCat/Cyclone-Intensity-ML)（在线展示：https://enm-aiir.pages.dev/）。上游描述为 `yolov8m-cls`，14个T值类别 `1.5, 2.0, ..., 8.0`，512×512输入；**权重实际类别映射、通道与预处理流程尚待实测核验**。此仓库为全新独立代码工程，不是上游Fork，模型权重与输入图像不纳入Git。

## 纳入的工作

1. **模型验收**：来源、上游Git版本与权重SHA-256；Ultralytics/PyTorch加载兼容性；核实`model.names`和14类对应关系；单图推理烟雾测试。
2. **输入契约**：卫星/通道、UTC时刻、亮温与增强图区别、中心裁切、缩放/填充、RGB/BGR、数据类型、归一化；避免默认CenterCrop遗漏风暴结构。
3. **推理后处理**：保留Softmax完整向量、众数T值及概率加权 `E[T|image] = Σ p_i T_i`，明确未经校准的概率性质。
4. **工程应用**：单图与批处理CLI、JSON/CSV、置信度可视化、气旋时间序列、输入和模型元数据追溯、CPU/GPU及可选ONNX/TensorRT部署。
5. **固定模型独立评估**：按完整气旋个例核实与上游训练/验证样本重叠风险，检验T值MAE/RMSE、分层偏差、校准与跨域泛化；区分作者自报与项目独立结果。

**不纳入**：训练数据集建设、训练/验证划分、梯度更新、微调、Trainer修改、损失函数研究、训练选模及训练时超参搜索。需要这些能力时，应到另一个独立仓库 `Cyclone-Intensity-Training` 进行研究。

## 与训练仓库的关系

本仓库独立于 `Cyclone-Intensity-Training`，没有共同Git历史、共同依赖锁文件或跨仓库相对路径。只接收满足约定的模型交付资产（权重本体不进Git）：`model_id`、`model_sha256`、模型结构与依赖版本、输入张量/预处理定义、有序类别表及目标物理量、输出语义、数据/评估适用范围与局限。不能假定新权重与上游模型的类别或预处理相同。

## 环境与科学边界

候选 Ubuntu、Conda、Python 3.11、PyTorch、Ultralytics、OpenCV、NVIDIA RTX 3090；实际版本与GPU可用性**待部署核验**。当前没有已验收的命令、依赖锁定文件或本项目精度报告。

**T-number、Dvorak CI与最大持续风速并非同一量；1分钟与10分钟平均风速不能混用。** Softmax概率未必经过校准；不应声称此项目具备业务定强资质。项目许可待独立决定；上游MIT说明不自动覆盖本工程引入的其他组件与资产。

AI工具工作纪律、已有Ultralytics/API问题经验和本地环境登记见 [AGENTS.md](AGENTS.md)。
